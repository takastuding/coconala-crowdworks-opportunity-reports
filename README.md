# coconala-crowdworks-opportunity-reports

Public opportunity-research reports for weekend-safe side work using labor, social-insurance, and FP knowledge.

## Report files

- Coconala: `reports/YYYY-MM-DD-coconala-report.md`
- CrowdWorks: `reports/YYYY-MM-DD-crowdworks-report.md`

Each report contains the relevant public listing URLs in its candidate table. This repository is for research and drafting only; it does not apply for work, contact clients, or retain private information.
