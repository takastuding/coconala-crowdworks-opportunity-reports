## 応募前に確認すること

### B案件1: ID 13187579

1. 初回契約時もクラウドワークス上で仮払い完了後に着手、という理解でよいか。
2. 連絡はクラウドワークス上を基本にできるか。Chatwork移行が必要な場合、サービス外連絡申請のタイミングはいつか。
3. 著作権の譲渡範囲、記名の有無、実績公開の可否はどうなるか。
4. 記事の最終的なファクトチェック責任は編集部と執筆者のどちらにあるか。NISA等の制度変更時の更新対応範囲も確認したい。
5. 源泉徴収の扱いはあるか。報酬表示が税込/税別どちら基準か。
6. 月10〜25本想定とのことだが、副業前提でまずは月2〜4本程度から開始できるか。

### B案件2: ID 13184577

1. 仮払い完了後の着手で問題ないか。また継続契約時の発注単位は1本ごとか、月単位か。
2. 平日日中の速報対応や即レスは必要か。土日中心で、平日は夜の確認でも運用可能か。
3. 著作権譲渡、記名の有無、ポートフォリオ掲載可否はどうなるか。
4. NISAや投資制度に関する記事で、法令・制度解釈・断定表現の最終確認責任は編集部側にあるか。
5. 源泉徴収の有無、単価アップ条件、継続時の最低本数を確認したい。
6. 題材選定は完全自走か、編集部から候補提示や方針相談があるか。

## 次回見直すべき条件

- 「社労士」「年金」「社会保険」ど真ん中の新規案件は、終了が早いので、平日朝の確認頻度を上げる価値がある。
- 「記事執筆」だけでなく「監修コメントあり」「SEO記事」「ニュース解説」「家計コラム」まで広げると、FP1級訴求先は増える。
- 応募優先は引き続き記事執筆だが、初回実績が1〜2本ついたら「監修」「リライト監修」案件にも入りやすくなる。
- 新規発注者は、本人確認、発注ルールチェック、レビュー件数、会社サイト・住所整合を最低ラインで確認する。

ライター実績はまだ拡大中の段階ですが、その分、一次情報の確認と事実関係のすり合わせを丁寧に行い、修正にも真面目に対応いたします。土日を中心にまとまった作業時間を確保できるため、まずは少本数からでも継続的にご一緒できれば嬉しいです。初回は実績作りの意味も込めて、条件面も含めて柔軟に相談可能です。

もし可能でしたら、まずは1本または少数本でお試し的にご依頼いただき、トンマナや進め方をすり合わせできればと考えております。必要であれば、想定読者に合わせた見出し案や構成案から対応いたします。どうぞよろしくお願いいたします。
