# ココナラ案件・出品市場リサーチ用プロンプト

Use the `coconala-growth-opportunity-research` skill if available. ココナラで、依頼者に合う社労士資格またはFP1級スキルを活かせる副業向けの「応募できる仕事」「退職相談・退職前後の制度整理に近い相談ニーズ」「出品サービス改善につながる市場シグナル」を調査し、候補を優先順位付きで日本語レポートにまとめてください。

## 重要な保存ルール

- 調査結果はこのリポジトリ内の `reports/YYYY-MM-DD-coconala-report.md` にMarkdownで保存する。
- スマホで読みやすいように、冒頭に「今日の結論」を置く。
- 保存後、可能なら `git add reports/YYYY-MM-DD-coconala-report.md`、`git commit -m "Add Coconala report YYYY-MM-DD"`、`git push origin main` を実行する。
- GitHub remoteや認証が未設定でpushできない場合は、ローカル保存とcommitまで行い、pushできなかった理由を報告する。

## 前提

- 依頼者は記事執筆経験・ココナラ実績がまだ少ない。
- 本業があるため、平日に重い対応は難しく、土日集中・非同期テキスト対応で進められるものを優先する。
- 第一候補は記事執筆、コラム、SEO記事、ブログ、説明文、FAQ、監修補助、リサーチ補助などの文章系案件。
- 同じく重要な候補として、退職相談、会社を辞める前後の不安整理、傷病手当金、失業保険、雇用保険、健康保険、任意継続、国民健康保険、年金切替、有給消化、離職票、退職後の家計など、現在出品している退職相談系サービスに近い相談ニーズも拾う。
- 第二候補として、土日対応可能で社労士・FP・労務・社会保険・年金・家計・保険・資産形成・ライフプラン等に紐づく相談・資料作成・出品改善テーマも拾う。
- 初期実績作りが目的なので、単価は安めでも可。ただし極端に搾取的な条件、継続負荷が大きすぎる条件、平日即レス必須、長時間拘束、経験者限定が強いものは避ける。
- 重要: 単に稼げる案件ではなく、依頼者の成長、専門性の可視化、次の高単価案件につながる実績作りを重視する。
- 重要: ココナラは「仕事に応募する」だけでなく「自分のサービスを買ってもらう」市場なので、良い応募案件が少ない場合も、売れている出品・検索結果・ブログからサービス改善案を出す。
- 重要: 案件の魅力だけでなく、購入者・発注者としての安全性・適切性も必ず確認する。ココナラ上で契約・決済が完結するか、外部連絡誘導がないか、評価・実績・本人情報、会社サイトと公開情報の整合、源泉徴収・著作権・資格名利用・最終責任範囲の不自然さを確認する。

## 調査対象

- ココナラ上の公開情報を中心に検索する。
- 「仕事を探す」「単発・スポットの仕事」「継続（時給/月給）の仕事」を確認する。
- 併せて「サービスを探す」「ブログを探す」「ノウハウ・素材を探す」から、依頼者の出品サービス改善につながる市場シグナルを確認する。
- 特に「退職相談」「退職前後の制度整理」「傷病手当金」「失業保険」「社会保険」「年金」「転職・キャリア相談」は、現在の出品サービスに近い領域として優先的に確認する。
- 検索カテゴリ例: ライティング・翻訳、コンサルティング・士業、資産運用・副業の相談、学習指導・資格・キャリア相談、ビジネス代行・事務代行、金融専門職、士業・専門職、人事。
- 検索キーワード例: 社労士, 社会保険労務士, 労務, 退職, 退職相談, 退職前, 退職後, 会社を辞めたい, 有給消化, 離職票, 傷病手当金, 失業保険, 雇用保険, 健康保険, 任意継続, 国民健康保険, 社会保険, 年金, 年金切替, 就業規則, 転職相談, キャリア相談, FP1級, FP, ファイナンシャルプランナー, 保険, 家計, 資産形成, ライフプラン, 記事執筆, ライター, 監修, コラム, 相談。

## 評価基準

1. 未経験・初期実績でも応募または出品改善に活かしやすいか
2. 土日中心・非同期テキスト中心で対応可能そうか
3. 社労士またはFP1級の差別化が効くか
4. 記事執筆実績・ココナラ評価・ポートフォリオ作りにつながるか
5. 単価・作業量・納期・継続性のバランス
6. 応募時や出品文で資格や実務知識を自然に訴求できるか
7. 依頼者の成長につながるテーマ・顧客接点・サービス改善価値があるか
8. 購入者・発注者の安全性、ココナラ規約面、著作権、源泉徴収、資格名利用、専門責任範囲に問題がないか
9. 成果保証・申請代行・個別法務/税務/投資助言のような高リスク領域に踏み込みすぎないか
10. 退職相談系の場合、退職代行・会社交渉・申請代行・受給保証ではなく、制度の一般説明、相談前整理、確認事項メモ、家計影響の整理として安全に受けられるか

## 出力形式

- 調査日時を明記する。
- 最初に「今日の結論」として、応募優先度の高い案件または出品改善アクションを3件以内で要約する。
- 候補をA/B/C/Dで表にする。A=応募・対応推奨、B=条件確認後に応募・対応、C=情報収集用、D=見送り推奨。
- 表の列は「総合」「対象名」「URL」「種別」「テーマ」「成長価値」「土日対応」「安全性」「懸念点」「次アクション」。
- 退職相談に近いものがあれば「退職相談マッチ候補」として、直接応募できる案件か、出品サービス改善に使う市場シグナルか、ブログ題材かを分けてまとめる。
- 別表で「市場シグナル・出品改善」をまとめる。列は「示唆」「根拠URL」「買い手ニーズ」「既存出品への活かし方」「優先度」。
- テーマは良いが購入者・発注者安全性や専門責任範囲に懸念がある場合は、総合をB以下に下げる。
- 経験者必須、平日常時対応必須、専門外、条件が悪すぎる、発注者リスクが高すぎる案件は「除外した案件・理由」に簡潔にまとめる。
- AまたはB案件には「応募前・出品前に確認すること」として、ココナラ上での契約・決済、源泉徴収、著作権、資格名・著者名・監修者名利用、専門内容の最終確認責任、断定表現や成果保証の可否などの質問を作る。
- 最後に、上位案件へ送る応募文または見積もり相談返信のたたき台を1つ作る。未経験・初期実績段階であることは必要に応じて正直にしつつ、社労士・FP1級スキル、土日集中対応、丁寧なリサーチ、初回は小さな範囲でも実績作りとして取り組む姿勢を自然に入れる。
- 新規に良い案件が見つからない場合も、検索したキーワード、弱い候補、次回見直すべき条件、既存出品やブログの改善案を報告する。
