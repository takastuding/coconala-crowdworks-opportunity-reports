## 市場シグナル・出品改善

1. **タイトルを「退職相談」単独から具体的な確認行動へ**
   - 推奨: 「退職前後のお金・手続きの不安を整理します｜失業給付・健康保険・年金の確認点」
   - 需要語が多い失業給付、健康保険、年金に加え、「退職前に会社へ確認」「次に何をするか」の表現が強い。

2. **提供形式は土日対応できる非同期・固定範囲にする**
   - 基本: 事前フォーム → 48時間以内（土日中心）に「確認点整理メモ」1枚＋質問リストを返信。
   - オプション: 追加のFAQ 3問まで。無制限チャット、即日、電話必須は設けない。

3. **ブログ/FAQの最初の3本**
   - 「退職前に会社へ確認したい10項目：有給・離職票・保険の整理」
   - 「任意継続・国民健康保険・扶養は、まず何を比べる？確認先チェックリスト」
   - 「傷病手当金と失業給付が気になるときの相談前メモ：断定せず確認する順番」

4. **信頼を作る境界文を冒頭と購入前のお願いに明記する**
   - 「会社への連絡・退職代行・交渉、申請代行は行いません」
   - 「受給可否・受給額・税額・投資成果を保証しません」
   - 「個別事情は勤務先、ハローワーク、保険者、年金事務所等に確認するための論点を整理します」

## 除外した案件・理由

| 区分 | 理由 |
| --- | --- |
| 退職代行・会社交渉 | 緊急性が高く、使用者との交渉/法的判断に近づくため。 |
| 傷病手当金・雇用保険の申請代行 | 書類作成・提出代行、受給可否の責任が生じやすい。今回の参照例にも申請代行サービスが存在するが、自サービスの入口にはしない。 |
| 「給付金をもらえる」「最大化」などの保証訴求 | 制度要件は個別であり、誤認・レピュテーションリスクが大きい。 |
| 電話即時対応・無制限チャット | 平日稼働と感情的負荷が膨らみやすく、副業の持続性に合わない。 |

## 応募前・出品前に確認すること

1. 取引、連絡、決済、納品はココナラ上で完結するか。
2. 成果物は記事/FAQ/制度の一般説明/相談前整理メモに限り、最終的な個別判断・申請責任を負わないか。
3. 退職代行、会社交渉、書類代筆・提出、受給保証、税務判断、個別投資助言を含まないか。
4. 平日は確認中心、作業と回答は土日中心でよいか。納期、修正回数、質問上限は明記できるか。
5. 記事なら著作権、二次利用、実績公開、監修/資格名の表示、断定表現の責任分担を確認できるか。
